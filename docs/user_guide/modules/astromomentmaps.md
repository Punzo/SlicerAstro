# AstroMomentMaps

Moment maps of a data cube: **0th** (integrated intensity), **1st**
(intensity-weighted velocity: the velocity field) and **2nd** (velocity
dispersion). The voxels used are those in a mask (a segment: all the
channels), or within a threshold range and a velocity range. The 0th moment
is the sum of the intensities times the channel width.
