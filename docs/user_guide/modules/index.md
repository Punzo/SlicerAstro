# Modules

The SlicerAstro modules are in the **Astronomy** category of the module
selector. Each module has a *Help & Acknowledgement* section and tooltips on
its controls.

```{toctree}
:maxdepth: 1

astrovolume
astrosmoothing
astromasking
astrostatistics
astroprofiles
astromomentmaps
astropvslice
astropvdiagram
astromodeling
astroreproject
astrosofiacatalog
```

All the long computations run in the background: a progress dialog shows
their progress and can cancel them; the application stays responsive.
