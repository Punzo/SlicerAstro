# AstroPVSlice

Interactive position-velocity (PV) slice. A line on the 0th moment map (red
view) defines a slice through the cube, shown in the other views and in 3D.
Move the end points of the line, rotate it (*Rotate*) or set its centre (in
pixels or world coordinates); the 3D view can be oriented parallel or
perpendicular to the slice. The axes of the PV view are the angular offset
along the line and the velocity.
