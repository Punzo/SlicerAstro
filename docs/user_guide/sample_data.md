# Sample data

The sample data sets are in the **Sample Data** module, category
**Astronomy**. They are downloaded from the
[`SampleData-v2`](https://github.com/Punzo/SlicerAstro/releases/tag/SampleData-v2)
release of SlicerAstro (checksums are verified) and cached locally.

| Sample | Content | Source |
|---|---|---|
| WEIN069 | HI data cube of a galaxy group | WHISP (van der Hulst et al. 2001) |
| WEIN069_MASK | SoFiA 2 mask (segmentation) and source catalogue of WEIN069 | SoFiA 2 (Westmeier et al. 2021) |
| NGC2403 | HI data cube (30″ resolution) | HALOGAS DR1 (Heald et al. 2011) |
| NGC2403_DSS | Optical image of the NGC 2403 field | Digitized Sky Survey 2 (red) |
| NGC891 | HI data cube, edge-on disk with extraplanar gas | HALOGAS DR1 |
| NGC3198 | HI data cube, regularly rotating disk | HALOGAS DR1 |
| NGC4631 | HI data cube, interacting group with tidal streams | HALOGAS DR1 |
| Antennae_HI | HI data cube of NGC 4038/4039 | VLA, Hibbard et al. (2001) |
| Antennae_CO | CO(2-1) data cubes, north and south fields | ALMA Science Verification |
| Antennae_MUSE | Hα and [N II] data cubes (continuum subtracted) | VLT/MUSE, Weilbacher et al. (2018) |
| Antennae_R | Optical R-band image | CTIO, Hibbard et al. (2001) |

The release notes of `SampleData-v2` describe how each file was prepared
(cutouts, binning) and the acknowledgements requested by each survey.
